\begin{abstract}
This project explores the effectiveness of K-truss bridge design, inspired by the structural efficiency of the Ikitsuki Bridge and the connectors of a Nintendo Switch. K-trusses are known for their ability to distribute loads effectively, which made them a favorable option. We also used a slide lock to enable sections to be printable within bed size requirements while also allowing quick assembly. We developed our design using CAD and performed an initial analysis for static loads using finite element methods in Onshape.
\end{abstract}

\begin{block}{Details}
\begin{itemize}
\item Challenges faced
\begin{itemize}
\item Clearing issues found during initial drawing review
\item Potential shrinkage in way of slide locks
\item Issues generating support material in Cura
\item Learning curve for CAD and FEM in Onshape
\end{itemize}
\item Print details
\begin{itemize}
\item Sliced using Cura, printed on Elegoo Neptune 3 Max
\item \qty{0.16}{\milli\meter} resolution, 20\% infill, grid infill pattern, tree supports
\item \qty{205}{\celsius} extruder, \qty{60}{\celsius} bed
\end{itemize}
\end{itemize}
