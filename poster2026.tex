\begin{abstract}
This project explores the effectiveness of Warren truss bridge design, inspired by the structural efficiency of the Kingston-Rhinecliff Bridge and our Nintendo Switch-inspired connectors. Warren trusses are known for their ability to distribute loads effectively through triangulated diagonals, making them a highly favorable option. We used a slide-lock and keyhole joint system to enable sections to be within the required dimensions while allowing for quick assembly. We developed our design and performed an initial analysis for static loads using finite element methods in Onshape. 
\end{abstract}

\begin{block}{Details}
\begin{itemize}
\item Challenges faced
\begin{itemize}
\item Interference from residual support material in slide-locks
\item Minimizing material usage, improve load/weight from 2025
\item Print warping and bed adhesion issues with large parts
\item Interoperability of prints from different printers
\end{itemize}
\item Print details
\begin{itemize}
\item Sliced using Cura and Creality Print
\item Printed on Elegoo Neptune 3 Max and Creality K1 Max
\item \qty{0.12}{\milli\meter} resolution, gyroid infil, normal supports
\item \qty{205}{\celsius} extruder, \qty{60}{\celsius} bed
\item 10\% infill in top piece; 12\% infill in the base, 15\% infill in sides, with sections reinforced with 20\% infill
\end{itemize}
\item Future work
\begin{itemize}
\item Snap-fit tolerancing calibration across multi-printer builds
\item FEA-guided variable infill zoning, reduce weight further
\end{itemize}
\end{itemize}
\end{block}
